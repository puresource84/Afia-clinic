Afia Clinic

A complete dental practice management suite for Odoo 18: patients, appointments, charting, clinical records, billing, insurance, lab work, stock and a patient portal. Built for dental clinics rather than adapted from a generic CRM.

Installs in one click. This module pulls in the entire suite — nineteen modules — as dependencies. Install it and the clinic is ready; there is nothing to add by hand and no load order to get right.

Four roles, one ladder

Each role includes everything the one below it can do, so staff are given a single role rather than a checklist of permissions.

  • Receptionist — appointments, patients, billing, lab orders, insurance claims
  • Hygienist — the above, plus dental and periodontal charting
  • Dentist — the above, plus prescriptions, clinical notes and treatment plans
  • Clinic Administrator — full access, including clinic configuration and staff accounts

In a small practice the dentist often runs the clinic as well. The Add Staff User wizard offers that directly, so an owner-dentist keeps every clinical capability and gains configuration without anyone editing groups by hand.
