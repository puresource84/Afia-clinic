Afia Dental Clinic

The foundation module for the Afia Clinic suite: patients, appointments, dentists, treatments, prescriptions and billing — built for dental clinics that need a real practice management system, not a generic CRM stretched to fit.

Start here. This is the required dependency for every other Afia Dental Clinic module — install this first, then add only the companion modules (charting, insurance, patient portal, Telegram reminders, ZainCash/PayTabs payments, and more) your clinic actually needs.

Key Features

  • Full patient records with medical history, allergies and demographics
  • Appointments backed by Odoo's native Calendar app — real start/end datetimes, dentist capacity awareness, ICS export, and a normal calendar view
  • Dentist and specialist management, including time shifts
  • Treatment catalog with categories and pricing
  • Prescriptions with a printable PDF report
  • Native multi-company support (company_id + record rules)
  • Doctor accounts created through an auditable invite flow with a real password reset link — not a silent, passwordless user creation
  • Consistent chatter/activity tracking across all clinical models

Built for Arabic-Speaking Clinics

  • Full Arabic (RTL) and English bilingual support
  • Designed for dental clinics in Iraq and the Arab world
  • Companion modules add Telegram reminders and ZainCash/PayTabs payment integration for the region

Compatibility

  • Odoo 18.0 Community Edition
  • Depends only on standard Odoo apps: Contacts, Employees, Accounting, Sales, Inventory, Calendar, Discuss

The Afia Clinic Suite

Afia Dental Clinic is the core of a modular suite covering clinical charting (odontogram, periodontal exams, SOAP notes), treatment planning and case acceptance, lab and sterilization tracking, insurance claims, a patient portal with online booking, multi-branch support, and commission/analytics reporting. Install only the modules your clinic needs — nothing is bundled in that you didn't ask for.
