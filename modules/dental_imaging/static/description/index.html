Dental Imaging

A6 v1: Per-tooth and per-visit photo/X-ray gallery (attachment-based). No DICOM required — any image format the browser can display.

Part of the Afia Clinic Suite — a comprehensive dental practice management solution built on Odoo 18, developed by ITCS (IT Corner Solutions).

Key Features

  • X-ray and intraoral image attachment per tooth or visit
  • Image categorization (periapical, panoramic, bitewing, CBCT)
  • Linked to dental chart and treatment records
  • Secure storage with patient-level access control

Compatibility

  • Odoo 18.0 Community & Enterprise
  • Arabic (RTL) and English bilingual support
  • Designed for dental clinics in Iraq and the Arab world
